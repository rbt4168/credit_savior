# Project preferences

Read `preferences.json` before preparing homework deliverables.

- Write homework answers in English by default.
- Typeset PDFs with LaTeX, including properly rendered equations and clear layout.
- Do not add an unsolicited references or "References and definitions" section.
- Follow explicit assignment requirements when they mandate a language or citations.
- Keep editable `.tex` sources with the local deliverables.
- Never place coursework, credentials, or private account data in tracked files.

Use `doc/installation-guide.md` when installing or running this repository.
